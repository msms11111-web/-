# قطرة — الإصدار التجريبي 0.1

موسوعة القهوة العربية «قطرة». موقع ثابت بلا أطر عمل ولا اعتماديات: HTML و CSS و JavaScript فقط.

## الصفحات المنفذة
- الصفحة الرئيسية
- فهرس الموسوعة والبحث المحلي
- إثيوبيا
- قوجي
- ديجا
- المعالجة المجففة
- ملف قوجي — ديجا — مجففة
- وصفة V60 التأسيسية
- منهج قطرة
- بوابة القهوة السعودية

## التشغيل المحلي
```bash
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## النشر
الموقع ثابت، فينشر على أي استضافة. المستودع مهيأ للثلاث الشائعة، وكلها مجانية
لموقع بهذا الحجم وتشمل شهادة HTTPS وشبكة توزيع عالمية:

| الاستضافة | الملف | الإعداد |
|---|---|---|
| **Cloudflare Pages** | `tools/build.sh` | Build command: `sh tools/build.sh` — Output directory: `/` |
| **Netlify** | `netlify.toml` | لا شيء، يُقرأ الملف تلقائيًا |
| **Vercel** | `vercel.json` | لا شيء، يُقرأ الملف تلقائيًا |

في الثلاث: اربط المستودع بالخدمة، وينشر كل دفعة إلى `main` تلقائيًا.

**العنوان يُضبط وقت البناء.** كل خدمة تمرر عنوان النشر الفعلي (`$URL` أو
`$VERCEL_PROJECT_PRODUCTION_URL` أو `$CF_PAGES_URL`) إلى `tools/set-site-url.py`،
فتتطابق وسوم canonical و Open Graph و `sitemap.xml` مع النطاق الحقيقي دون تدخل —
سواء كان نطاقك المخصص أو النطاق الافتراضي للخدمة.

> العنوان المحفوظ في المستودع `https://qatra.example/` عنوان **مؤقت** لا وجود له.
> لا يضر لأن أمر البناء يستبدله، لكن إن نشرت الملفات يدويًا دون تشغيل أمر البناء،
> شغّل `tools/set-site-url.py` بنطاقك أولًا وإلا أشارت وسوم canonical إلى نطاق وهمي.

### رفع يدوي (FTP أو cPanel)
```bash
python3 tools/set-site-url.py https://your-domain.com/
```
ثم ارفع محتويات المجلد كما هي. لا يوجد أي خطوة بناء أو اعتماديات.

## تغيير عنوان الموقع
```bash
python3 tools/set-site-url.py https://example.com/
```
يحدّث `robots.txt` و`sitemap.xml` ووسوم canonical و Open Graph وبيانات JSON-LD في
كل صفحة، وروابط صفحة 404 (التي يجب أن تكون مطلقة لأنها تُعرض من أي مسار).
آمن للتشغيل أكثر من مرة، وينتقل بين نطاق جذر ومسار فرعي دون تراكم.

## فحص الروابط
```bash
python3 tools/check-links.py
```
يمر على كل صفحات الموقع ويتأكد أن كل `href` و`src` داخلي يشير إلى ملف موجود.
يستنتج مسار الموقع من وسم canonical، فلا يحتاج تعديلًا عند تغيير النطاق.
يعمل تلقائيًا قبل كل نشر، وفي GitHub Actions عبر `.github/workflows/ci.yml`.

- إضافة الإحالات الكاملة للمصادر.
