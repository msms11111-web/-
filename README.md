# قطرة — الإصدار التجريبي 0.1

موسوعة القهوة العربية «قطرة». موقع ثابت بلا أطر عمل ولا اعتماديات: HTML و CSS و JavaScript فقط.

## الصفحات المنفذة
- الصفحة الرئيسية
- فهرس الموسوعة والبحث المحلي
- إثيوبيا
- قوجي
- ديجا
- المعالجة المجففة
- ملف قوجي — ديجا — مجففة
- وصفة V60 التأسيسية
- منهج قطرة
- بوابة القهوة السعودية

## التشغيل المحلي
```bash
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## النشر — Cloudflare Pages
مجاني بلا حد على النطاق الترددي، وشبكته تشمل جدة والرياض والدبي.

**الإعداد لمرة واحدة:**
1. [dash.cloudflare.com](https://dash.cloudflare.com) ← **Workers & Pages** ← **Create** ← **Pages** ← **Connect to Git**
2. اختر مستودع `msms11111-web/-`، والفرع `main`
3. الإعدادات:
   - Build command: `sh tools/build.sh`
   - Build output directory: `/`
4. **Save and Deploy**

بعدها ينشر كل دفعة إلى `main` تلقائيًا، وكل فرع آخر يحصل على رابط معاينة خاص.

**عند ربط نطاق مخصص:** أضفه في **Custom domains**، ثم أضف متغيرًا في
**Settings ← Environment variables**:
```
SITE_URL = https://your-domain.com/
```
هذه الخطوة ليست تجميلية: `CF_PAGES_URL` يبقى يعطي عنوان `pages.dev` حتى بعد ربط
النطاق، فبدون `SITE_URL` تشير وسوم canonical إلى العنوان القديم وتُحسب نسختين من
الموقع محتوى مكررًا في نتائج البحث.

**سلوك البناء:**

| الحالة | العنوان المستخدم | الأرشفة |
|---|---|---|
| `main` مع `SITE_URL` | نطاقك المخصص | مسموحة |
| `main` بدونه | `*.pages.dev` | مسموحة |
| أي فرع آخر | رابط المعاينة | ممنوعة |

منع أرشفة المعاينات مقصود، وإلا نافست نسخ الفروع الموقعَ الحقيقي في نتائج البحث.

> العنوان المحفوظ في المستودع `https://qatra.example/` عنوان **مؤقت** لا وجود له.
> لا يضر مع Cloudflare لأن أمر البناء يستبدله، لكنه يضر لو رفعت الملفات يدويًا.

### رفع يدوي (FTP أو cPanel)
```bash
python3 tools/set-site-url.py https://your-domain.com/
```
ثم ارفع محتويات المجلد كما هي. لا يوجد أي خطوة بناء أو اعتماديات.

## تغيير عنوان الموقع
```bash
python3 tools/set-site-url.py https://example.com/
```
يحدّث `robots.txt` و`sitemap.xml` ووسوم canonical و Open Graph وبيانات JSON-LD في
كل صفحة، وروابط صفحة 404 (التي يجب أن تكون مطلقة لأنها تُعرض من أي مسار).
آمن للتشغيل أكثر من مرة، وينتقل بين نطاق جذر ومسار فرعي دون تراكم.

## فهرس البحث
```bash
python3 tools/build-search-index.py
```
يستخرج نص كل الصفحات إلى `assets/search-index.json`، فيبحث الموقع في المحتوى
كله لا في بطاقات الفهرس وحدها. يعمل تلقائيًا قبل كل نشر.

البحث في `assets/app.js` يطبّع العربية: التشكيل والتطويل والهمزات والألف
المقصورة والتاء المربوطة والأرقام العربية. ويشترط بداية الكلمة للكلمات القصيرة
(مع احتساب السوابق `و ف ب ك ل` و`ال`)، وإلا طابقت «دلة» كلمة «أدلة».

إن تعذّر تحميل الفهرس يرجع البحث تلقائيًا إلى تصفية البطاقات، فلا يتعطل.

## تدقيق الوصولية
```bash
python3 -m http.server 8099 &
pip install playwright && playwright install chromium
python3 tools/audit-a11y.py
```
أداة صيانة محلية (ليست جزءًا من النشر) تفحص تباين الألوان وترتيب العناوين
وتسميات الحقول وأثر التركيز في كل الصفحات. شغّلها بعد إضافة محتوى أو تغيير ألوان.

تفصيلان يجعلانها صادقة: تقرأ ألوان محطات التدرجات (وإلا حُسب النص الفاتح على
تدرّج داكن كأنه على خلفية فاتحة، فظهرت عشرات الأخطاء الوهمية)، وتفحص أثر
التركيز بالضغط الفعلي على `Tab` لأن `:focus-visible` لا يُفعَّل بنداء
`focus()` البرمجي.

## فحص المصادر الخارجية
```bash
python3 tools/check-external-links.py
```
يتحقق أن كل مصدر مُحال إليه ما زال يستجيب. يفرّق بين رابط ميت (خطأ) وشبكة
محجوبة (ليست خطأ في الموقع). يعمل في GitHub Actions لأن بيئة التطوير قد لا
تصل إلى الإنترنت.

## فحص الروابط
```bash
python3 tools/check-links.py
```
يمر على كل صفحات الموقع ويتأكد أن كل `href` و`src` داخلي يشير إلى ملف موجود.
يستنتج مسار الموقع من وسم canonical، فلا يحتاج تعديلًا عند تغيير النطاق.
يعمل تلقائيًا قبل كل نشر، وفي GitHub Actions عبر `.github/workflows/ci.yml`.

- إضافة الإحالات الكاملة للمصادر.
