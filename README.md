# قطرة — الإصدار التجريبي 0.1

موسوعة القهوة العربية «قطرة». موقع ثابت بلا أطر عمل ولا اعتماديات: HTML و CSS و JavaScript فقط.

## الصفحات المنفذة
- الصفحة الرئيسية
- فهرس الموسوعة والبحث المحلي
- إثيوبيا
- قوجي
- ديجا
- المعالجة المجففة
- ملف قوجي — ديجا — مجففة
- وصفة V60 التأسيسية
- منهج قطرة
- بوابة القهوة السعودية

## التشغيل المحلي
```bash
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## النشر
الموقع يُنشر على GitHub Pages عبر `.github/workflows/deploy.yml`، الذي يفحص الروابط
الداخلية أولًا ثم يرفع محتوى المستودع كاملًا.

لتفعيله لأول مرة: **Settings ← Pages ← Source: GitHub Actions**. بعدها يُعاد النشر
تلقائيًا مع كل دفعة إلى `main`، ويمكن تشغيله يدويًا من تبويب Actions لأي فرع آخر.

العنوان الحالي: `https://msms11111-web.github.io/-/`

## تغيير عنوان الموقع
عند حجز نطاق خاص، يُضبط العنوان في كل الملفات بأمر واحد:
```bash
python3 tools/set-site-url.py https://example.com/
```
يحدّث السكربت `robots.txt` و`sitemap.xml` ووسوم canonical و Open Graph في كل صفحة،
وروابط صفحة 404 (التي يجب أن تكون مطلقة لأنها تُعرض من أي مسار). آمن للتشغيل أكثر من مرة.

بعد تغيير النطاق: حدّث `SITE_URL` في `tools/check-links.py`، وأضف ملف `CNAME`،
واضبط النطاق في **Settings ← Pages ← Custom domain**.

## فحص الروابط
```bash
python3 tools/check-links.py
```
يمر على كل صفحات الموقع ويتأكد أن كل `href` و`src` داخلي يشير إلى ملف موجود.
يعمل تلقائيًا قبل كل نشر.

## قبل الإطلاق العام
- حجز النطاق والبريد الرسمي، ثم تشغيل `tools/set-site-url.py`.
- رفع الصور الأصلية وحقوقها، واستبدال الهوية البصرية المؤقتة في الصفحة الرئيسية.
- ربط لوحة إدارة للصور والمحتوى.
- إضافة الإحالات الكاملة للمصادر.
